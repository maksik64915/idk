# Гомін — PWA

Месенджер із прямим звʼязком між пристроями: повідомлення, фото, голосові,
аудіо- та відеодзвінки, акаунти з паролем.

Це прогресивний вебзастосунок: встановлюється на телефон з іконкою на
робочому столі, запускається на весь екран без адресного рядка й
відкривається без мережі.

```
index.html             весь застосунок (стилі та код усередині)
manifest.webmanifest   назва, іконки, колір, ярлики
sw.js                  service worker: офлайн-кеш і оновлення
icons/                 192, 512, maskable 512, apple-touch, favicon
.github/workflows/     автоматична публікація на GitHub Pages
```

---

## Важливо: потрібен https

Service worker, камера й мікрофон працюють лише на `https://` або на
`http://localhost`. Якщо просто відкрити `index.html` подвійним кліком
(`file://`), встановлення й офлайн-режим не запрацюють. Тому застосунок
треба десь розмістити — нижче три способи, від найпростішого.

## Спосіб 1 — GitHub Pages (безкоштовно, автоматично)

1. Створіть репозиторій на GitHub.
2. Завантажте туди **вміст цієї теки** (`index.html` має опинитися в корені,
   не в підтеці). Кнопка **Add file → Upload files**, перетягніть усе разом
   із прихованою текою `.github`.
3. **Settings → Pages → Source: GitHub Actions**.
4. Вкладка **Actions** покаже запуск «Deploy PWA to GitHub Pages». За хвилину
   сайт буде за адресою `https://<логін>.github.io/<репозиторій>/`.
5. Відкрийте цю адресу на телефоні → меню браузера → **«Встановити застосунок»**.

## Спосіб 2 — Netlify Drop (без реєстрації репозиторію)

Відкрийте [app.netlify.com/drop](https://app.netlify.com/drop) і перетягніть
туди цю теку. Через кілька секунд отримаєте посилання виду
`https://щось.netlify.app` — воно вже з https і одразу готове до встановлення.

## Спосіб 3 — локальна перевірка

```bash
python3 -m http.server 8080
```
і відкрийте `http://localhost:8080` — на localhost браузер дозволяє і service
worker, і доступ до камери з мікрофоном.

## Як встановити на телефон

**Android (Chrome, Edge, Samsung Internet).** Відкрийте адресу → меню (⋮) →
«Встановити застосунок» або «Додати на головний екран». Застосунок також
пропонує це сам: **Налаштування → Застосунок → Встановити застосунок**.

**iPhone (Safari).** Кнопка «Поділитися» → «На екран «Додому» → «Додати».
Safari не показує автоматичної пропозиції — у налаштуваннях застосунку є
підказка з кроками.

**Компʼютер (Chrome, Edge).** Іконка встановлення в адресному рядку праворуч.

## Оновлення

Замінили `index.html` — застосунок сам помітить нову версію при наступному
запуску й покаже внизу «Доступна нова версія → Оновити». Вручну:
**Налаштування → Застосунок → Перевірити оновлення**.

Якщо змінюєте файли, підніміть номер у першому рядку `sw.js`:

```js
const VERSION = 'homin-v1.4.0';   // → 'homin-v1.4.1'
```

Інакше старий кеш може лишитися в декого з користувачів.

## Що працює офлайн

Сам застосунок, усі ваші чати, медіа й налаштування — вони зберігаються на
пристрої та зашифровані паролем акаунта. Не працює офлайн лише те, для чого
потрібен співрозмовник: надсилання повідомлень (вони стануть у чергу й підуть
самі, щойно зʼявиться мережа) і дзвінки.
